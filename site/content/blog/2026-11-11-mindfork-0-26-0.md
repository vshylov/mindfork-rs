[mindfork 0.26.0](https://github.com/vshylov/mindfork-rs/releases) is out. The
interface can now be tried in a browser tab, with nothing installed.

## Try it in a tab

[mindfork.io/try/](@/try.md) runs `mindfork demo` in your browser. Press **Start**,
wait for a download of about 25 MB, and the chat is in front of you with a question
already in the input box.

**It is the program, not a recording of it.** The binary is this release's own,
built for 32-bit x86, running inside a PC emulated in WebAssembly. The screens, the
keys, the commands, the streaming and the settings are the ones you would install:
`F1` opens the help, `Esc` the chat list, `Ctrl+P` the settings, `F3` the assistant's
self-model.

**It is a demo of the interface, not a session with a model.** A scripted engine
answers with a few fixed replies, whatever you ask. The emulated machine has no
network, so a real model cannot be connected there.

- Nothing is installed, nothing you type leaves the tab, and closing the tab
  discards everything.
- It starts in about a second once downloaded: the machine is not booted in your
  browser but restored from a state saved while the demo was already running.
- It wants a keyboard and a desktop-sized window. It is slower than on your own
  computer, and the terminal is the browser's: fonts and a few keys differ.

To use the app for real, [install it](@/install.md) and run `mindfork demo` on your
own machine — or connect a model.

## The same demo as a file

Every release now carries `mindfork-webdemo.tar`: that page with everything it
loads. Unpack it into an empty folder, serve the folder
(`python -m http.server --directory <folder>`), open it and press **Start**.

The demo hands you other people's work — the emulator, a Linux kernel, the terminal
it draws in — so it comes with a list written by the release's build out of the very
files it packs: what each piece is, the text of its licence, and where the source of
exactly that build is. The page shows that list under the terminal.

## Fixes

- **mindfork starts on a system with no CA certificates.** In a minimal container
  with no certificate bundle the app ended at start with a panic about a TLS client.
  It now starts: a local server over plain HTTP works as before, and an HTTPS request
  fails when it is made, with a certificate error.
- **The demo's companion is English in the settings too.** `mindfork demo` showed
  Russian as the *Framework language* of a profile whose content is English.
- **Solid bars without lines across them.** In the screenshots and the animated demo,
  the accent bar down a message and a scrollbar's thumb showed a thin line of the
  background between every two rows. They are drawn whole now.

## Your data

Nothing moves to a new format: the settings and the chats keep their schemas, nothing
is migrated at the first start, and going back to 0.25.0 needs no backup restored.
