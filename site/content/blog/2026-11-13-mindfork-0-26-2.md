[mindfork 0.26.2](https://github.com/vshylov/mindfork-rs/releases) is out. It is a
small release with one fix and the command that goes with it.

## The persona that did not arrive

A profile's system message is the persona: who the model is and how it answers. Each
conversation keeps its own copy of it, taken when the conversation is created — the
assistant can change its own system message with a tool, and a copy is what lets it.

The first start opens a conversation at once, with the default text. Write a persona
into **Settings → Profiles → System message**, go back to that conversation, say
hello — and the reply came from the default "helpful assistant", not from your
persona, however many times you regenerated it. The edit had reached only the
conversations created after it, and nothing on the screen said so.

Now a conversation you have not written in yet takes the profile's new text, as if it
were created after the edit. A conversation already under way keeps the text it
started with, as before: its replies so far were written under it. The settings row
now says this, and so does the note `/profile system` leaves.

## `/system`

To change the persona of a conversation already under way, type `/system` in it:

- bare, it puts the conversation's system message into the input box, ready to edit
  and send back;
- `/system <text>` replaces it;
- `/system reset` takes the profile's current text;
- `/system clear` removes it.

The profile itself is not changed, so other conversations keep theirs. The next reply
follows the new text.

## Your data

Nothing is migrated: the settings stay at schema 7 and the chats at 8. Going back to
0.26.1 needs no backup restored — checked with the published 0.26.1 on data this
version wrote.
