Try the interface

The program's own interface, running in this browser tab. Nothing to install.

This is a demo of the program's interface, not a session with a real model. A scripted engine answers with a few fixed replies, whatever you ask. Everything around them is the program itself: its screens, keys, commands, streaming and settings.

Downloads about @DOWNLOAD_MB@ MB once. It needs a keyboard and a desktop-sized window: the interface is drawn at @COLS@ × @ROWS@ characters, as large as the window allows.

This window is smaller than the interface needs, or this device has no keyboard. The demo will start, but its text will be small: it is made for a desktop browser.

Click the terminal, then type; a question is already waiting in the input box, and Enter sends it. F1 help and every command · Esc the chat list · Ctrl+P settings · F3 the assistant's self-model · Ctrl+Q or /exit quit.

Your browser keeps Ctrl+N, Ctrl+T and Ctrl+W for itself. Type /new, /thoughts and /mouse instead: every key has a typed command.

What is running here

mindfork @VERSION@, the same program you would install, built for 32-bit x86 and running inside a PC emulated in WebAssembly, in this tab. Nothing is installed, nothing you type leaves your browser, and closing the tab discards it. The engine that answers is a script; the machine has no network, so a real model cannot be connected here.

It is slower here than on your computer, and the terminal is the browser's rather than yours: fonts, colours and a few keys differ. To use it for real, install it and run mindfork demo or connect a model.
