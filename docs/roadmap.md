# Возможный Roadmap

## Инструменты (tools)
- **Извлечение контента и реранкинг для `web_search`** — сейчас только заголовки/сниппеты выдачи; помечено «на будущее». Загрузка страницы + извлечение текста + реранк под запрос.
- **Новые инструменты**: чтение/запись локальных файлов (под выключателем, как Python), `fetch_url` (вытащить и саммаризировать страницу), вычисления/калькулятор, текущее время/дата.
- **MCP-клиент** — подключение внешних MCP-серверов как источника инструментов (естественное расширение `ToolRegistry`).
- **Подтверждение опасных инструментов** — интерактивный prompt перед `python_exec`/файловыми операциями (human-in-the-loop).

## Лента и UI чата
- **Per-message сворачивание/выделение/копирование** — явно отложено за M3, с пометкой «учесть тумблер мыши `Ctrl+W`». Выделение отдельного сообщения, копирование одного блока.
- **Горизонтальный скролл широких таблиц** (вместо текущего клипа с «…») — задел из ADR 0003.
- **Подсветка кода через тему** — сейчас `syntect` со своей палитрой, не согласован с dark/light (задел ADR 0003).
- **Поиск по тексту внутри ленты** (`/`-поиск с подсветкой и переходами).
- **Регенерация с вариациями** — не просто `Ctrl+R` тем же запросом, а с другим семплингом / выбор из нескольких вариантов ответа.
- **Редактирование любого (не только последнего) сообщения** с ветвлением истории.

## Управление чатами и профилями
- **Папки/теги для чатов** — группировка в списке `Ctrl+L`/`Esc`.
- **Экспорт чата в файл** (Markdown/JSON) — сейчас есть только копирование в буфер (`F5`); добавить сохранение на диск.
- **Pin / закрепление важных чатов** наверху списка.
- **Шаблоны промптов / сниппеты** — быстрые вставки часто используемых системных сообщений или затравок.
- **Поиск по содержимому чатов** (а не только по заголовку) — полнотекстовый поиск через SQLite FTS.

## Движок и надёжность
- **Переключение моделей на лету** без полного перезапуска секции настроек (быстрый селектор модели прямо в чате).
- **Поддержка мультимодальности** (изображения) — если модель/`llama-server` поддерживает vision; передача картинок из буфера/файла.

## Прочее
- **Голосовой ввод/вывод** (STT/TTS) — амбициозно, но для TUI-чата заметная фича.
- **Кастомная раскладка клавиш** — в «Интерфейсе» уже есть поле под это (помечено как задел с M9), но фактическое применение кастом-биндингов не сделано.
- **Применение темы из конфигурации цветов** — пользовательская палитра поверх auto/dark/light.
