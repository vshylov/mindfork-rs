# Russian versions of the licence and the disclaimer

Design plan (AGENTS.md §1) for a track that gives the two legal texts —
`LICENSE` (MIT) and `DISCLAIMER.md` — a Russian counterpart, shown on the app's
`F1` tabs and in the Windows installer's wizard pages.

Task (user, 2026-08-22; branch `feat/legal-ru-translations`).

## 1. What exists today, and why it says "English only"

Both texts are English and deliberately not localized. The rule is written down
in three places, each pointing at the next:

- `shared/credits.rs` — "Legal text in English, language-neutral — not
  localized", for `LICENSE_TEXT` and `DISCLAIMER_TEXT` alike. The `F1`
  "License"/"Disclaimer" tabs read those two `include_str!`s directly and never
  touch a locale bundle (spec §11.7).
- `packaging/windows/mindfork.iss` — "Both texts stay English in the ru wizard,
  as they do in the app — only the page chrome around them is localized";
  `LicenseFile` points at the root `LICENSE`, `InfoBeforeFile` at the generated
  `disclaimer.rtf`.
- `tools/wizard_rtf.py` — the same sentence again, next to the converter that
  renders `DISCLAIMER.md` into the wizard's RTF.

The `ru` chrome around them *is* localized already: the `F1` tab labels
(`ui.help.tab.license`, `ui.help.tab.disclaimer`) and the wizard's page caption
and lead-in (`[Messages]`, `WizardInfoBefore`/`InfoBeforeLabel`). So a Russian
user meets a page titled in Russian that then hands them 4 500 words of legal
English. That is the gap this track closes.

Two constraints from the earlier decisions survive untouched (journal:
"a disclaimer for what the models say and do", "the Windows installer shows the
license and the disclaimer"):

- **`LICENSE` stays byte-identical to the canonical MIT text.** The `MIT` SPDX
  identifier in `Cargo.toml`, `packaging/nfpm.yaml` and the README badge is only
  truthful while it is, and scanners match the file by similarity. A translation
  therefore cannot live in that file, or in any file a scanner would pick up as
  *the* licence — which rules out a root `LICENSE.ru.md`, since `licensee` and
  friends match `LICENSE*` by glob.
- **A generated wizard copy, never a hand-maintained one.** The text a user
  accepts at install time must not be able to drift from the repository's.
  `tools/wizard_rtf.py` already exists for exactly this, and its `PAIRS` list was
  written as a list because "the license page may one day want the same
  treatment" — which is today.

## 2. The legal shape of a translation

A translated MIT licence is **not** the licence: the grant is the English text,
and a translation that disagrees with it in some subtle way would be a second,
unintended contract. The universal practice (Creative Commons, the FSF, every
distribution that ships translated licences) is to publish translations as
*informational*, with the original named as authoritative.

So both Russian files open with one short paragraph saying: this is an
unofficial translation for convenience; the English `LICENSE` / `DISCLAIMER.md`
is the text that has legal force; in case of any discrepancy the English wins.
Nothing else in either file is added, removed or softened — section for section,
sentence for sentence.

## 3. Forks (for the user's decision)

**F1 — which text the app shows.**
- **(a) Follow the interface language** *(recommended)*: `Lang::Ru` → the Russian
  text, every other language (including external locales) → English. One text on
  screen, matching the language everything else in the app is in.
- (b) Show both, Russian appended after English on the same tab. Doubles a tab
  that is already long, and buries whichever one you came for.
- (c) A key inside the tab toggles the language. A third meaning for a keypress
  on a dialog that already spends `Tab`/`←→`/`↑↓`, for a document read once.

Note (b)'s and (c)'s common alternative — a *separate* pair of tabs — is closed
by geometry, not taste: the `ru` tab strip already measures exactly 76 of the
dialog's 76 minimum columns, and a gate test
(`the_help_tab_strip_fits_the_dialog_in_every_locale`) exists precisely because
the sixth tab overflowed it once.

**F2 — the Windows wizard.**
- **(a) Per-language pages** *(recommended)*: Inno's `[Languages]` section takes
  `LicenseFile`/`InfoBeforeFile` per entry, so the `ru` wizard shows the Russian
  licence and disclaimer and the `en` wizard is byte-for-byte what it shows
  today. Both Russian pages are generated by `tools/wizard_rtf.py` (the RTF is
  pure ASCII — every Cyrillic character becomes a `\uNNNN?` escape — so the
  compiler needs no encoding negotiation and `cyrillic_scan.py` has nothing to
  trip over).
- (b) Leave the wizard English and translate only the app. Half the feature: the
  wizard is where the acceptance actually happens.

**F3 — the "unofficial translation" preamble** (§2).
- **(a) One paragraph at the top of each Russian file** *(recommended)*.
- (b) No preamble — the files claim to be the licence and the notice. Not
  advisable, and it is the one part of this track that is hard to walk back.

**F4 — do the Russian files ship with the product?**
- **(a) Yes, alongside the originals** *(recommended)*: the release archives'
  doc set, the `.deb`/`.rpm`/`.pkg` doc directory, and the installer's `[Files]`
  — the same four places `DISCLAIMER.md` travels through today. Two small text
  files; a user who accepted a Russian page in the wizard can find that text on
  disk afterwards.
- (b) App and installer only; the repository copy is the only readable one.

> User's decision, 2026-08-22: F1 (a), F2 (a), F3 (a), F4 (a) — see §7.

## 4. Design

### 4.1 Where the files live

```
docs/legal/LICENSE.ru.txt       the MIT text in Russian + the §2 preamble
docs/legal/DISCLAIMER.ru.md     the seven-section notice in Russian + the preamble
```

`docs/legal/` rather than the repository root: the root's `LICENSE*` namespace
belongs to the scanners (§1), and a directory named for what it holds is where a
second translation would go without anyone having to decide again.

**The licence translation is `.txt`, the disclaimer's is `.md`** — each keeps its
original's shape, because each is read by the renderer written for that shape.
The app's "License" tab reflows paragraphs and has no Markdown in it: a `#` or a
`[link](target)` in that file would reach the screen verbatim, and the wizard's
RTF converter would carry the same text into the installer. The extension is
what says so, so the tempting "make it Markdown like its neighbour" edit does not
look like tidying; a gate test pins the paragraphs-only shape as well.

### 4.2 The app

`shared/credits.rs` gains the two `include_str!`s and one accessor per text:

```rust
pub fn license_text(lang: Lang) -> &'static str
pub fn disclaimer_text(lang: Lang) -> &'static str
```

`Lang::Ru` → the Russian file, anything else → the English one. The mapping
lives in `credits` rather than at the call site so that the `F1` tabs, and
anything that later wants the same text, cannot disagree about it — the same
reasoning that put `secret_key()` on the settings struct in the external-API-key
track. `screens/chat/popups.rs` passes the `Locale` it already has into
`license_lines`/`disclaimer_lines` (`component_lines` takes it already).

Both renderers are unchanged otherwise: the licence reflows paragraphs, the
disclaimer goes through our own Markdown renderer (ADR 0003) with the hanging
indent for list items. The Russian disclaimer is written to the same subset the
English one uses, so nothing new reaches either renderer.

### 4.3 The installer

`tools/wizard_rtf.py`'s `PAIRS` grows from one entry to three:

| source | generated |
|---|---|
| `DISCLAIMER.md` | `packaging/windows/disclaimer.rtf` (as today) |
| `docs/legal/DISCLAIMER.ru.md` | `packaging/windows/disclaimer-ru.rtf` |
| `docs/legal/LICENSE.ru.txt` | `packaging/windows/license-ru.rtf` |

The English `LICENSE` still needs no conversion — plain ASCII, pointed at
directly. `--check` covers all three, so CI's `lint` job fails on any of them
drifting.

`mindfork.iss` moves `LicenseFile`/`InfoBeforeFile` out of `[Setup]` and into
the `[Languages]` entries, one pair per language, so there is exactly one place
that answers "which text does this wizard show". `[Files]` gains the two Russian
documents next to `LICENSE`/`DISCLAIMER.md`.

### 4.4 Gates

- `tools/cyrillic_scan.py` — the two new files are Cyrillic by construction, so
  they join `SKIP_FILES` with a comment naming why (the same treatment
  `locales/ru.json` and the RU→EN glossary get). The generated RTFs need
  nothing: they are pure ASCII.
- `tools/link_check.py` — the Russian files link back to the English originals,
  so their relative targets get one `../` more than the root files' do.
- New `credits` tests: both translations are embedded and non-empty; the
  accessors map `Ru`/`En`/`Ext` to the right text; each translation carries the
  §2 preamble and the same section structure as its original (heading count and
  order for the disclaimer, "paragraphs only" for the licence); the existing
  English gates are untouched.

## 5. Scope, and what is deliberately not in it

- **Only the two legal texts.** `README.md`, `CHANGELOG.md`, `docs/install.md`
  and the site stay English; translating the documentation is a different track
  with a different maintenance cost.
- **No new locale keys.** The texts are documents, not UI strings: they stay out
  of `locales/*.json` (which the `F1` legal tabs have always bypassed) — a 4 500
  word legal notice inside a JSON string is unreviewable, unwrappable and
  undiffable.
- **External locales get English.** A `data/locales/<code>.json` bundle cannot
  bring its own legal translation; that would be user-supplied legal text
  shipped as ours.

## 6. Verification

A live run is **not** required (AGENTS.md §3): two documents, one accessor pair,
a tab renderer's argument list and packaging file lists — no engine, memory, tool
or provider path is touched.

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`;
- `python tools/cyrillic_scan.py`, `link_check.py`, `doc_index_check.py`,
  `wizard_rtf.py --check`;
- the `.iss` compiles (`ISCC.exe`), and the wizard is launched in both locales
  (`/CURRENTUSER /LANG=en|ru`) to confirm each page shows the right text — the
  precedent run for the legal pages did exactly this, and the note it left
  applies again: drive the pages with `Tab` + arrows, never the accept radio's
  `Alt+A` accelerator, which is a different letter in the `ru` wizard;
- the `F1` tabs read in both interface languages in a real terminal.

  wizard pages, F3 (a) the "unofficial translation" preamble, F4 (a) ship the
